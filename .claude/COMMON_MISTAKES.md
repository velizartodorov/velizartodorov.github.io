## Top 5 Critical Mistakes

### 1. Adding comments when writing code

**Symptom**: New or edited code ships with explanatory comments (`// why`, block comments, JSDoc).
**Check**: Before saving, scan the diff for any `//`, `/* */`, or `/** */` you added.
**Fix**: Don't add comments. Let the code speak for itself — clear names, small functions.
Only exception: the user explicitly asks for a comment.
